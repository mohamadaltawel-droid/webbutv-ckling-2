Om CSS

CSS (Cascading Style Sheets) är ett språk som används för att beskriva utseendet och formateringen av ett dokument som skrivs i HTML eller XML. CSS används för att styra layout, färger, typsnitt, marginaler, padding och andra visuella aspekter av webbsidor. Genom att separera innehåll (HTML) från presentation (CSS) kan utvecklare skapa mer flexibla och lättunderhållna webbplatser.

Olika typer av CSS

  • Inline CSS: CSS som skrivs direkt i HTML-elementets "style"-attribut.
  • Internal CSS: CSS som placeras inom en "style"-tagg i HTML-dokumentets "head".
  • External CSS: CSS som placeras i en separat fil med filändelsen ".css" och länkas till HTML-dokumentet.
